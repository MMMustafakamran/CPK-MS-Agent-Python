# CLI and Rich Threads testing

This folder is a small test area for the CopilotKit CLI and the three Rich
Threads pages. Run the CLI first, complete browser authentication, then copy or
compare the files from the relevant scenario folder in the generated app.

## Scenarios

- `copilotkit-cli/` - CLI login, project selection, generated environment, and checks.
- `threads-drawer/` - the documented `CopilotThreadsDrawer` setup.
- `headless-threads/` - the highlighted `useThreads`, thread selection, and pagination code.
- `thread-and-history-lifecycle/` - explicit thread switching, new-thread controls, and history notes.

These are intentionally small. The CLI-generated project supplies the package
configuration, runtime credentials, backend agent, and global provider.
